# 📁 Mes Projets

## 🇫🇷 Présentation

Bienvenue sur mon dépôt 👋  

Ce repository regroupe l’ensemble de mes projets académiques, personnels et techniques dans les domaines de l’**intelligence artificielle**, des **systèmes embarqués**, de la **robotique**, de l’**IoT**, de la **vision par ordinateur** et du **développement logiciel**.

L’objectif de ce dépôt est de centraliser mes travaux, de suivre mon évolution en ingénierie et de constituer un **portfolio technique structuré** à destination des recruteurs et collaborateurs.

Les projets présents couvrent notamment :
- 🧠 **Intelligence artificielle / Machine Learning** : classification, apprentissage supervisé et non supervisé, analyse de données
- 🤖 **Robotique & systèmes embarqués** : contrôle de systèmes matériels, bras robotisé, intégration hardware/software
- 📡 **IoT (Internet of Things)** : capteurs, acquisition de données, communication sans fil, systèmes connectés
- 👁️ **Vision par ordinateur** : détection, reconnaissance faciale, traitement d’images
- ⚙️ **Développement logiciel & bas niveau** : Python, C/C++, Rust, MATLAB, OpenCV, TensorFlow
- 🔧 **Électronique & FPGA** : conception de systèmes numériques et prototypage matériel

Chaque dossier correspond à un projet indépendant (ex : *Projet IoT*, *Machine Learning*, *Voiture autonome en Rust*, *Identification faciale*, *Projet de fin d’études AI-in-Colibry-NPU*, *Stage 2025 Exosquelette*, etc.).

Certains fichiers volumineux (datasets, exécutables, environnements virtuels) sont exclus via `.gitignore` afin de garantir un dépôt propre, léger et maintenable.

Ce dépôt évolue continuellement avec l’ajout de nouveaux projets et l’amélioration des projets existants.

📬 Profil GitHub : https://github.com/Oloua

## 🇬🇧 Overview

Welcome to my **Projects repository** 👋  

This repository contains my academic, personal, and technical projects in the fields of **Artificial Intelligence**, **Embedded Systems**, **Robotics**, **IoT**, **Computer Vision**, and **Software Development**.

The main goal of this repository is to centralize my work, track my engineering progress, and serve as a **structured technical portfolio** for recruiters and collaborators.

The projects include:
- 🧠 **Artificial Intelligence / Machine Learning**: classification, supervised & unsupervised learning, data analysis
- 🤖 **Robotics & Embedded Systems**: hardware control, robotic arm, hardware/software integration
- 📡 **IoT (Internet of Things)**: sensors, data acquisition, wireless communication, connected systems
- 👁️ **Computer Vision**: detection, facial recognition, image processing
- ⚙️ **Software & Low-level Development**: Python, C/C++, Rust, MATLAB, OpenCV, TensorFlow
- 🔧 **Electronics & FPGA**: digital systems design and hardware prototyping

Each folder corresponds to an independent project (e.g. *IoT Project*, *Machine Learning*, *Autonomous Car in Rust*, *Face Recognition*, *Final Year Project AI-in-Colibry-NPU*, *2025 Internship Exoskeleton*, etc.).

Large files (datasets, executables, virtual environments) are excluded using `.gitignore` to keep the repository clean and lightweight.

This repository is continuously evolving with new projects and improvements.
